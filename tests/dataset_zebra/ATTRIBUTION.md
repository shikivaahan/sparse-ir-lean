# ZebraLogicBench subset attribution

The JSON records under the grid-size directories are unmodified records selected
from the public `grid_mode/test` split of
[`allenai/ZebraLogicBench`](https://huggingface.co/datasets/allenai/ZebraLogicBench),
revision `a909ef550df0d218775ea6fc950368db34c98680`.

ZebraLogicBench accompanies:

> Bill Yuchen Lin, Ronan Le Bras, Kyle Richardson, Ashish Sabharwal, Radha
> Poovendran, Peter Clark, and Yejin Choi. “ZebraLogic: On the Scaling Limits of
> LLMs for Logical Reasoning.” arXiv:2502.01100, 2025.

The dataset is used under the Creative Commons Attribution 4.0 International
license: <https://creativecommons.org/licenses/by/4.0/>. This repository adds the
directory layout, manifest, provenance fields, and checksums; it does not alter the
selected source records. No endorsement by the dataset authors is implied.
